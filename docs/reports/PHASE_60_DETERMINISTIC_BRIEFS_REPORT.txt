1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Phase 60 continues Milestone 38 (Capture and Resume) of Project Continuum v1.4.0
"Universal Resume Anywhere". Conforming to invariants I-06 (Derived Briefs & Indexes
are Non-Authoritative), I-09 (Explicit Disclosure for External AI Services), and I-10
(Comprehensive Secret Redaction), this phase implements:
1. `DeterministicResumeBriefGenerator`:
   - Pure local, deterministic generation answering the 6 core continuity questions:
     1. Purpose & Working Goal: Derived from checkpoint context or activity definition.
     2. Last Completed Work: Ordered authoritative accomplishments with provenance.
     3. Key Decisions & Constraints: Structured design decisions and rationale.
     4. Blockers: Explicit blockers or standardized '[None reported]' indicator.
     5. Unresolved Questions: Open issues and provenance notices for non-user data.
     6. Next Concrete Actions: Prioritized next actions or safe activity resumption.
2. Ground Truth & Zero-Invention Rule (I-06):
   - Generates derived content without ever hallucinating missing facts.
   - When inputs are sparse, emits explicit placeholders (e.g. '[No explicit architectural decisions recorded]').
3. Comprehensive Secret Redaction (I-10):
   - Automatically sanitizes generated briefs against DaemonSanitizer regex matchers
     (OpenAI, Anthropic, AWS, GitHub tokens, passwords).
4. Optional AI Enhancement Gate (I-09):
   - AI enhancement strictly requires explicit user consent (`consent_granted=True`).
   - Discloses provider, model, and transmitted fields.
   - Safely and silently falls back to local deterministic generation on any failure,
     timeout, or when AI is disabled/declined.
   - Zero external network transfer without consent.
5. REST API & Markdown Formatter:
   - `GET /api/v1/resume/brief?activity_id=<id>&format=json|markdown`
   - Formatter generating standard GitHub Flavored Markdown continuity briefs.

3. ARCHITECTURAL CONTRACTS & INVARIANTS ENFORCED
--------------------------------------------------------------------------------
A. Non-Authoritative Derivation (I-06):
   - Briefs declare `is_ai_enhanced=False` and `generator_id="continuum_deterministic_v1"`.
   - Authoritative ground truth remains solely in structured checkpoint files.

B. Zero External Transfer Without Consent (I-09):
   - External callbacks are blocked unless `AiEnhancementConsent.consent_granted=True`.
   - If AI provider throws an exception or network drops, execution cleanly falls back
     to local deterministic generation without failing the user operation.

C. Secret Redaction (I-10):
   - All text generated for purpose, completed work, decisions, blockers, questions,
     and next actions is sanitized via DaemonSanitizer before serialization.
