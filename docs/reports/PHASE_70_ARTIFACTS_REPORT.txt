1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Phase 70 delivers explicit distinction, lifecycle tracking, and strict security
guards for checkpoint artifacts in Project Continuum:
  - References by default: 0-byte snapshot copy, live file pointer preserved.
  - Optional user-selected snapshots: safe text files (<=512 KB per file, 2 MB
    total checkpoint budget) captured as immutable history with timestamps.
  - Explicit labeling: live reference vs snapshot copy, capture timestamp, and
    storage visibility (workspace_local, external_uri, embedded_snapshot, missing).
  - Resilient missing resources: references degrade gracefully to 'missing'
    without crashing or mutating state; snapshots survive live file deletion.
  - Strict directory guard: folders/directories are NEVER snapshot-copied.
  - Strict privacy protections (Invariant I-10): high-risk credential files
    (.env, id_rsa, *.pem, secrets.json, etc.) are excluded from snapshot capture;
    inline secrets are redacted via DaemonSanitizer.
  - Seamless UI integration: manual capture modal includes artifact mode toggle;
    read-only snapshot modal renders rich artifact cards and expandable previews.

GATE REQUIREMENT:
  "Users understand what is linked vs copied."
  -> Fully verified: UI and API explicitly display distinct badges, storage
     visibilities, and clear warning messages for live references vs snapshots.

2. COMPONENT ARCHITECTURE & IMPLEMENTATION
================================================================================
A. Core Artifact Management Engine (core/artifact_manager.py):
   - ArtifactError, ArtifactSnapshotError, ArtifactPrivacyError, ArtifactSizeLimitError
   - ArtifactManager constants:
     * MAX_SNAPSHOT_FILE_BYTES = 512 * 1024 (512 KB)
     * MAX_TOTAL_SNAPSHOT_BYTES = 2 * 1024 * 1024 (2 MB)
     * SAFE_TEXT_EXTENSIONS (code, markup, structured data)
   - normalize_path(path_or_uri, workspace_root):
     Converts absolute filesystem paths within workspace to relative POSIX paths.
   - resolve_local_path(path_or_uri, workspace_root):
     Safely resolves relative POSIX paths and file:// URIs without traversal escape.
   - inspect_resource(path_or_uri, workspace_root):
     Classifies files into references/snapshots, detects directories, high-risk
     credentials, file sizes, and computes SHA-256 digests.
   - create_reference(path_or_uri, ...):
     Default mode; creates a live link with 0 bytes content copied.
   - create_snapshot(path_or_uri, ...):
     Explicit consent mode; reads text, sanitizes secrets, checks budgets.
   - resolve_artifact_status(artifact, workspace_root):
     Detects missing files, diverged files, deleted workspace files.
   - validate_and_process_artifacts(raw_artifacts, ...):
     Batch validation and normalization pipeline.

B. Data Model Enhancements (core/checkpoint.py):
   - ArtifactReference:
     * Added storage_visibility: 'workspace_local' | 'external_uri' | 'embedded_snapshot' | 'missing'
     * Added is_present: Optional[bool]
     * Added metadata: Dict[str, Any]
     * Properties: is_snapshot, is_reference
     * Resilient from_dict() and to_dict() serialization

C. Manual Capture Pipeline Integration (core/manual_capture.py):
   - ManualCaptureEngine now validates artifacts through ArtifactManager:

     * Enforces directory snapshot prohibition (downgrades or excludes).

     * Enforces privacy exclusions for credential files and redaction of inline secrets.

D. HTTP Endpoints & REST Layer (server/routes.py):
