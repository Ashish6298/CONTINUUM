1. PHASE OVERVIEW & REQUIREMENTS IMPLEMENTATION
--------------------------------------------------------------------------------
Phase 79 delivers the complete offline Device Transfer Guide and cross-device package
manager (`core.device_transfer.DeviceTransferManager`), ensuring that users can move
their authoritative Continuum activities, checkpoints, DAG relations, and decisions
between devices without requiring network sync, servers, cloud accounts, or third parties.

Key Architectural Guarantees:
1. Pure Local-First, Offline Transfer:
   - Encapsulates state into self-verifying, portable archives (`.continuum-transfer.tar.gz`).
   - Requires zero network listeners, external cloud providers, authentication servers,
     or live sync daemons. Operates via standard air-gapped media (USB flash drives, local drives).

2. Transparent Data Scope (docs/DEVICE_TRANSFER_GUIDE.md):
   - Explicitly documents included authoritative files (`activities/*/activity.json`,
     `activities/*/checkpoints/*.json`, `manifest.json`, configs, permitted artifacts)
     versus excluded ephemeral data (SQLite databases `*.db`, temporary files `*.tmp`,
     runtime session tokens `*.token`, daemon lockfiles `*.pid`).

3. Version Compatibility Matrix:
   - Full compatibility on matching format versions (`continuum-backup-v1.0` / `1.0.0`).
   - Minor version differences (e.g. `1.0.1` / `continuum-backup-v1.1`) are accepted
     gracefully with informative audit notices in transfer logs.
   - Incompatible major versions (e.g. `2.0.0`) are blocked before mutation, raising
     `IncompatibleDeviceVersionError` to prevent corruption.

4. Missing Destination Artifact Reconciliation:
   - When importing on a new machine where external files referenced by the source device
     do not exist on the destination filesystem:
     * `_audit_and_reconcile_missing_artifacts()` scans imported checkpoints.
     * Marks missing external paths with `missing_on_device: true`, `storage_visibility: "missing"`,
       and records `device_origin_path`.
     * DAG continuity, timeline queries, and checkpoint resumption remain 100% unbroken.

5. REST API Control Plane:
   - `POST /api/v1/transfer/package`: Generates transfer archive.
   - `POST /api/v1/transfer/inspect`: Pre-flight inspection of archive version and counts.
   - `POST /api/v1/transfer/import`: Imports package with automatic missing-artifact handling.
