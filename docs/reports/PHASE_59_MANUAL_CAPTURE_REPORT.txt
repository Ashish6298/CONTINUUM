1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Phase 59 initiates Milestone 38 (Capture and Resume) of Project Continuum v1.4.0
"Universal Resume Anywhere". Conforming to invariants I-01 (Stable IDs), I-02 (Durable
Commit Confirmation), I-08 (Opt-In & Bounded Automation), and I-10 (Comprehensive
Secret Redaction), this phase implements:
1. `ManualCaptureEngine`: Pure local manual checkpoint capture engine.
2. Complete data capture flow supporting:
   - Target Activity binding (create/select).
   - Structured state & progress tracking.
   - Completed work, pending actions, and blockers (multiline lists).
   - Explicit design decisions and rationale.
   - Context narrative and live references.
   - Selected artifact references (references vs snapshot mode).
3. Robust Double-Submission & Idempotency Defense:
   - In-memory time-window deduplication (30s cache) combined with deterministic
     intent hashing and caller-supplied `idempotency_key`.
   - Prevents duplicate clicks or rapid retries from polluting checkpoint history.
4. Privacy Sanitization & Secret Exclusions:
   - Evaluates input context, decisions, completed work, and artifact snapshot
     contents against DaemonSanitizer regex pattern matchers and custom denied terms.
   - Excludes high-risk credential files (.env, *.key, *.pem) from artifact lists.
5. REST API Endpoints:
   - `GET /api/v1/activities` (paginated activity listing)
   - `POST /api/v1/activities` (activity creation)
   - `GET /api/v1/checkpoints` (paginated checkpoint listing)
   - `POST /api/v1/checkpoints/manual` (manual checkpoint capture)
6. Web Control Dashboard UI:
   - Added "Capture Checkpoint" header action button with dark glassmorphic modal dialog.
   - Keyboard accessible, clear commit progress state, and toast feedback.
7. Automation & AI Independence:
   - Manual capture functions 100% offline with zero external network or AI dependencies.

3. ARCHITECTURAL CONTRACTS & INVARIANTS ENFORCED
--------------------------------------------------------------------------------
A. Durable Commit Confirmation (I-02):
   - Checkpoints are written to atomic `.tmp` files, flushed to disk, replaced, and
     indexed in SQLite before confirmation is returned.
   - Failures raise `CaptureStorageError` with original cause preserved; no false success.

B. Double-Submission Defense (I-08, I-14):
   - Identical submissions or duplicate idempotency keys within the 30-second window
     are rejected with `DuplicateSubmissionError` (HTTP 409 Conflict).

C. Comprehensive Secret Redaction (I-10):
   - API tokens (sk-*, ghp_*, AKIA*, etc.), passwords, and custom denied terms are
     masked before disk writes. High-risk credential files are excluded from artifacts.

D. Offline Independence Gate:
   - Engine executes synchronously and locally. Does not require or invoke any external
     AI service or remote network connection.
