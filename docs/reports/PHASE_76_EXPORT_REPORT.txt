1. PHASE REQUIREMENTS & SPECIFICATION AUDIT
--------------------------------------------------------------------------------
Phase 76 implements clean, selective, portable versioned export capabilities
for individual activities and targeted checkpoints across Project Continuum:
- Selective Activity & Checkpoint Export:
  * Supports single and multiple activity exports.
  * Supports selective checkpoint filtering under activities.
  * Gracefully handles empty selections (0 activities, valid empty archive)
    and large selections (50+ checkpoints streamed without unbounded memory).
- Clean, Portable, Versioned Format:
  * Self-describing `manifest.json` at archive root with format version
    "continuum-export-v1.0".
  * Full preservation of IDs, relations, and DAG lineage (`parent_checkpoint_id`,
    `branch_source_checkpoint_id`).
  * Full preservation of Provenance records (`captured_by`, `provenance_type`,
    `is_authoritative`).
  * Full preservation of Decision records (`decision`, `rationale`, `constraints`).
  * Distinction of live reference vs embedded snapshot artifacts (`ArtifactMode.REFERENCE`
    vs `ArtifactMode.SNAPSHOT` with `snapshot_content`).
- Privacy and Secret Exclusions:
  * Automatic sanitization and redaction through `PrivacyManager` for all exported
    metadata, titles, descriptions, tags, checkpoint contexts, completed work,
    pending actions, decisions, resume briefs, and snapshot contents.
  * Verified exclusion of GitHub PATs, AWS keys, passwords, and API secrets.
- Gate Invariant Verification:
  * Users understand this is an export, not a complete backup.
  * Explicit `archive_type` declaration:
    "PORTABLE_EXPORT (Selective, portable activity/checkpoint export. NOT a complete system backup)."
  * Export verification rejects misrepresentation of exports as full backups.
