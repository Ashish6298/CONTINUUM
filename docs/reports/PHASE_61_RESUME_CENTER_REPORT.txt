1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Phase 61 continues Milestone 38 (Capture and Resume) of Project Continuum v1.4.0
"Universal Resume Anywhere". Conforming to invariants I-03 (Read-Only Historical Views),
I-06 (Derived Briefs are Non-Authoritative), and I-12 (Non-Regression of Core Workflows),
this phase implements:
1. Dedicated Universal Resume Center UI:
   - Recent & active activity listing with type, status, and last update time.
   - Prominent Deterministic Resume Brief display answering the 6 core continuity questions.
   - Checkpoint timeline evolution panel listing historical milestones.
   - 1-Click "Copy Brief" and "Capture Checkpoint" action triggers.
2. Unobtrusive Integrated Entry Points:
   - Header button "⚡ Resume Center" smoothly flips the view between Prompt Composer
     and Resume Center without page reloads or layout breakage.
   - Keyboard accessibility: Enter/Space navigation on activity lists, ARIA listbox roles.
3. Loading, Empty, and Error States:
   - Displays animated loading indicator during data retrieval.
   - Helpful empty states guiding users to create their first activity.
   - Error banners handling network/storage failures.
4. REST API Endpoint:
   - `GET /api/v1/activities/detail?activity_id=<id>` returning activity metadata,
     latest checkpoint, timeline summary, and preformatted markdown resume brief.
5. End-to-End Continuity Gate Verification:
   - Create activity -> capture checkpoint -> close/reopen process -> resume works
     100% offline with zero external network or service requirements.
