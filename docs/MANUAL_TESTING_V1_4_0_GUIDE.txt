STEP 3: CAPTURE AUTHORITATIVE CHECKPOINTS (Phases 54 & 59)
================================================================================
Tests immutable checkpoint snapshots, decisions, blockers, and progress:

    python -c "
    from storage.activity_store import ActivityStore
    from core.checkpoint import UniversalCheckpoint
    from core.activity import DecisionRecord

    store = ActivityStore('D:/CP')
    activities = store.list_activities(limit=1)
    act_id = activities[0].id

    # Create Checkpoint #1
    chk1 = store.create_checkpoint(UniversalCheckpoint(
        activity_id=act_id,
        structured_state={'auth_provider': 'local_jwt', 'jwt_algorithm': 'HS256'},
        progress={'milestone': 'Architecture Defined', 'completion_pct': 25},
        completed_work=['Audited current session management', 'Defined token lifespan'],
        pending_actions=['Implement token revocation list', 'Write integration tests'],
        decisions=[
            DecisionRecord(
                decision='Use SHA-256 HMAC for signing',
                rationale='Fast, zero external dependencies required',
                constraints=['Requires 256-bit secret key']
            )
        ],
        blockers=['Redis dependency is not configured yet'],
        context='Phase 1 of auth refactoring completed.'
    ))
    print(f'Committed Checkpoint 1: {chk1.id} (Parent: {chk1.parent_checkpoint_id})')

    # Create Checkpoint #2 (Child of Checkpoint #1)
    chk2 = store.create_checkpoint(UniversalCheckpoint(
        activity_id=act_id,
        parent_checkpoint_id=chk1.id,
        structured_state={'auth_provider': 'local_jwt', 'jwt_algorithm': 'HS256', 'revocation': 'in_memory'},
        progress={'milestone': 'Revocation Implemented', 'completion_pct': 60},
        completed_work=['Implemented in-memory token blacklist', 'Added expiry checks'],
        pending_actions=['Add persistent fallback store', 'Run load tests'],
        blockers=[],
        context='Blacklist working in local tests. Redis blocker resolved.'
    ))
    print(f'Committed Checkpoint 2: {chk2.id} (Parent: {chk2.parent_checkpoint_id})')
    "

Expected Output:
- Checkpoints committed atomically with parent DAG references.
- Indexed into SQLite FTS5 store automatically.

STEP 5: CHECKPOINT TIMELINE & DIFF COMPARISON (Phases 63 & 64)
================================================================================
Tests paginated time travel and state delta comparison:

    python -c "
    from storage.activity_store import ActivityStore
    from core.diff import CheckpointDiffEngine

    store = ActivityStore('D:/CP')
    act = store.list_activities(limit=1)[0]
    timeline = store.get_timeline(act.id, limit=10)

    print(f'Timeline for activity {act.id}: {len(timeline)} checkpoints')
    for i, chk in enumerate(timeline):
        print(f'  [{i+1}] {chk.id} - Progress: {chk.progress.get(\"completion_pct\")}% - At: {chk.timestamp}')

    # Compare Checkpoint 1 vs Checkpoint 2
    if len(timeline) >= 2:
        chk1, chk2 = timeline[1], timeline[0]
        diff = CheckpointDiffEngine.compute_diff(chk1, chk2)
        print('\n--- CHECKPOINT DIFF ---')
        print('Added Completed Work:  ', diff.added_completed_work)
        print('Resolved Blockers:     ', diff.resolved_blockers)
        print('State Changes:         ', diff.state_diff)
    "

Expected Output:
- Detailed breakdown of work completed, blockers resolved, and state mutations between checkpoints.

STEP 8: COMPLETE BACKUP & PORTABLE EXPORT (Phases 76 & 77)

    from core.backup import CompleteBackupEngine, PortableExportEngine
    from storage.activity_store import ActivityStore

    store = ActivityStore('D:/CP')

    # 1. Complete Backup (Full Disaster Recovery Tarball)

    backup_path = backup_engine.create_backup(output_path='D:/CP/continuum_backup.tar.gz')

    export_engine = PortableExportEngine(store)
    activities = store.list_activities(limit=1)
    export_path = export_engine.export_activities(
        activity_ids=[activities[0].id],
        output_path='D:/CP/portable_auth_export.tar.gz'
    )
    print(f'Portable Export created: {export_path}')
    "

Expected Output:
