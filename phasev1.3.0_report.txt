1. OBJECTIVE & ROOT CAUSE RESOLUTION
--------------------------------------------------------------------------------
In Continuum v1.2.0, transferring long conversations across web AI interfaces
(ChatGPT, Claude, Gemini, DeepSeek) resulted in severe context loss:
  a) DOM Virtualization: React/ProseMirror unmounts offscreen turns when
     conversations grow long, leaving only the visible viewport in the DOM.
  b) Naive Slicing: ContextCompressor was constrained by `messages.slice(-4)`
     and a hardcoded 2000 token budget, discarding project requirements,
     architectural decisions, and earlier working code artifacts.

In v1.3.0, the approved triad (Approach A + B + C with Smart Digest default)
was implemented to ensure complete context preservation across unlimited turns.

2. IMPLEMENTED ARCHITECTURE & CAPABILITIES
--------------------------------------------------------------------------------
A. Smart Digest 5-Tier Compression Engine:
   - Tier 1: Project Goal & Ground Intent (User objective, tech stack, constraints).
   - Tier 2: Ground Truth Code Artifacts (Deduplicated latest file implementations).
   - Tier 3: Conversation Progression & Milestone Digest (Chronological summary).
   - Tier 4: Active Conversation Trail (Verbatim recent 6-8 turns + exact errors).
   - Tier 5: Immediate Execution Directive (Concrete continuation directives).
   - Model-Tailored Syntax: Claude XML, Gemini hierarchical tiers, DeepSeek
     compact blocks, ChatGPT operational checklist.
   - Priority-based overflow management: Preserves active task and code first,
     condensing intermediate milestones when under token pressure.

B. In-Session Conversation Accumulator:
   - Platform Conversation ID Extraction:
     * ChatGPT: /c/([a-zA-Z0-9-]+)
     * Claude: /chat/([a-zA-Z0-9-]+)
     * Gemini / Google AI Studio: /(?:app|prompts)/([a-zA-Z0-9_-]+)
     * DeepSeek: /a/([a-zA-Z0-9_-]+)
   - Schema & Isolation: Isolated sessionStorage with versioned keys:
     `continuum_chat_v130_${platform}_${conversationId}` (max 250 turns).
   - Streaming Reconciliation: Detects active streaming (`isStreaming()`) and
     updates the current assistant turn in-place without generating duplicates.
   - User-Initiated Cold-Start Recovery:
     * Never silently auto-scrolls the viewport.
     * Displays an incomplete-history notification when DOM is truncated.
     * User clicks [Recover conversation history].
     * Runs bounded upward sweep with scroll-pause hydration.
     * Restores user's initial scroll position upon completion.
     * Concurrency locks reject overlapping recovery jobs.

C. Three Context Modes & Companion UI:
   - Smart Digest (Default): Target ~8,000 tokens (5-tier structured digest).
   - Full History: Target ~24,000 tokens (comprehensive chronological trail).
   - Quick Task: Target ~2,500 tokens (focused fix & immediate issue only).
   - User Interface Enhancements:
     * Context mode selection pills with active indicators.
     * Persistent mode selection via localStorage.
     * Dynamic token estimation display (~N tokens).
     * Collapsible full prompt preview drawer.
     * Clear history button with instant session reset.
